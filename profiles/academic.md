# academic：科研论文

适用信号：存在论文稿、研究问题、实验材料或参考文献，且目标涉及科研论证与学术写作。只有论文链接的普通产品项目不自动匹配。

## 引用规则

- [core](../rules/core.md)、[factual-integrity](../rules/factual-integrity.md)、[scope-control](../rules/scope-control.md)。
- [concise-writing](../rules/concise-writing.md)、[technical-accuracy](../rules/technical-accuracy.md)。
- [current-deliverable](../rules/current-deliverable.md)；已有阶段或提交记录要求时补选 [change-traceability](../rules/change-traceability.md)。

## 场景补充

- 将研究问题、方法、贡献和证据对应起来；不能把设计意图、相关性或单个案例提升为已证实的因果结论或普遍优势。
- 报告实验条件、数据划分、基线、评价口径及结果来源；材料未提供时不得补造。不要把验证集调参结果表述为独立测试结果。
- 保持摘要、正文、表图与结论中的数值和贡献声明一致；新颖性、最优性与显著性须有相应证据支持。
- 核验引文元数据与原文支持范围；未读原文时不能声称已完成论断核验。已有引用键及格式按项目约定保留。
- 沿用投稿模板、符号表和术语；不能为了润色改变方法含义或隐藏局限。计划开展的实验使用计划语态。

## 组合边界

与 software 组合时区分代码正确性和实验有效性；与 proposal 组合时区分已经获得的结果与拟开展的工作。不要因存在 `.bib` 文件就声称参考文献已核验。
