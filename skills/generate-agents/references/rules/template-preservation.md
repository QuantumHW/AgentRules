# 保留模板与验证实际版面

## 适用场景

依据固定模板编辑申请书、报告、表单等文档，或任务对 Word 等格式文件的版面有明确要求。普通 Markdown 不自动引入 Word 原生检查。

## 行为约束

- 写作前读取目标区域的填写提示，区分固定标题、字段、示例和占位内容；遵守分条、连续叙述、篇幅等实际要求。填写后替换示例，不把内部填写提示混入正式正文；固定填报说明按模板和授权保留。
- 保留模板标题、编号、小节、表格字段及列宽、页面设置、页眉页脚、页码和样式。只在授权区域调整必要的跨页设置或扩展表格行，不借内容增长重构模板。
- 内容增长允许自然分页；不能靠大量空段落撑出指定分页。用户要求固定分页时使用目标格式的分页或段落控制，并检查前后衔接。
- 沿用用户指定的工作文件及原始模板；获授权编辑前保留可恢复的原件或副本，恢复方式及位置沿用项目约定，不覆盖需保留的原件，也不制造多个并行终稿。备份、图源及检查产物放在已确认的辅助位置；只读任务不创建备份或保存文稿。
- Word 正文使用原生段落、编号、表格和内嵌图片，不残留 Markdown 标记。图示的工具、风格、字体及图源保存位置取自实际要求；图与正文的术语、流程、图题和引用对应。
- 修改后核对内容及授权边界。格式文件还应检查结构是否损坏；涉及长段落、表格、图片或排版时，渲染检查分页、标题衔接、跨页、图题及边框，不交付标题独占空页、文字裁切、正文隐藏或表格意外合并的文件。
- 指定 Microsoft Word 为最终版面依据时，交付前在 Word 原生界面检查；辅助渲染不能代替原生验收。工具不可用或检查未完成时，明确未验证项，不宣称版面通过或已可提交。

## 推荐行为

先确认模板与编辑区域，再完成局部修改，核对前后差异及实际显示；工作文件、恢复副本和辅助记录各有明确用途，最终交付仍指向同一份指定文稿。

## 例外

用户明确要求重做模板、转换格式或交付多个用途不同的成品时按其要求执行，不将模板保护变成禁止必要变更。固定措辞、章节号、分页要求与工具选择只在目标项目有依据时采用。

## 冲突关系

[scope-control](scope-control.md) 决定修改与备份授权，[current-deliverable](current-deliverable.md) 约束正式名称和过程材料。验证通过不扩大编辑范围；保留模板也不能掩盖 [factual-integrity](factual-integrity.md) 所要求报告的事实缺口。
