# academic：科研论文

适用信号：存在论文稿、研究问题、实验材料或参考文献，且目标涉及科研论证与学术写作。只有论文链接的普通产品项目不自动匹配。

## 场景补充

- 将研究问题、方法、贡献和证据对应起来；不能把设计意图、相关性或单个案例提升为已证实的因果结论或普遍优势。
- 报告实验条件、数据划分、基线、评价口径及结果来源；材料未提供时不得补造。不要把验证集调参结果表述为独立测试结果。
- 保持摘要、正文、表图与结论中的数值和贡献声明一致；新颖性、最优性与显著性须有相应证据支持。
- 核验引文元数据与原文支持范围；未读原文时不能声称已完成论断核验。已有引用键及格式按项目约定保留。
- 沿用投稿模板、符号表和术语；不能为了润色改变方法含义或隐藏局限。计划开展的实验使用计划语态。

### 论文叙事与表达（中英文）

- 围绕证据最充分、最有区分度的核心贡献组织全文，主动说明优势体现在哪个问题、条件和结果上，并在正文中解释关键数值及其意义，不让读者自行从表格推断贡献。
- 按研究问题、方法依据和验证结论组织叙事，不按“做了什么、试过什么、哪些失败了”的研发时间线写工作汇报。每个实验必须承担验证主张、解释机制、检验边界或揭示权衡的明确职责；无论证职责或重复的实验从正文删除或合并，不因此删除原始数据。复现方法所需的步骤和影响结论的反证必须保留。
- 禁止用“遗憾的是”“令人失望的是”等措辞评价自身结果，也不得用无依据的“仅”“仍明显落后”“效果有限”或对应英文表达自我削弱。不代审稿人罗列推测性弱点，不反复道歉、预先辩解或在已有证据支持的结论后附加泛化保留句。真实差异、必要限定和适用边界直接按事实陈述，不按词表机械删除有信息价值的表述，如“仅需 1 MB 内存”或“仅适用于无环图”。
- 依据研究目标和应用需求确定主要评价维度，不为无关指标组织排名。调整评价维度或比较口径必须有独立于结果输赢的理由，交代口径及可比条件；不得因结果不占优就事后挑选有利指标、撤掉相关强基线或隐去影响核心主张的比较。
- 结果不占优时，直接说明实际差异，并仅在目标差异、资源约束或合理权衡有证据支持时据此解释。不得用笼统的“输了”概括整项工作，也不得把未达目标包装成设计选择；缺少权衡依据时收窄相应主张，不编造解释。
- 摘要与引言按“问题—现有缺口—核心思路—最有说服力的结果”建立主线，突出有证据支撑的差异和贡献，不堆叠研发过程或预设质疑。结果尚未获得时不得补造数字或把预期写成实测。
- 结论强化核心贡献、关键结果和适用价值，不突然加入正文未分析的自我否定或无依据的弱点清单。影响结论成立的真实限制应在相应分析或必要的局限部分交代，结论保留必要范围，不作超出证据的总结。
- 用户要求检查防御性写作时，逐处给出原句、具体问题与可直接替换的改写；区分冗余自我削弱和必要事实限定，不把所有否定句、低于基线的结果或局限描述都判为防御性表达。改写必须保留数值、比较条件和结论范围；证据不足时指出缺口，不补造更有利的结果。

### 英文论文写作

- 叙述前人已完成的具体研究、方法提出、实验过程和发现时，使用一般过去式，如 `Smith et al. proposed ...`。仍然成立的普遍事实、理论和方法机制按语义使用现在式；概述延续至今的研究进展时可用现在完成式，不因出现引文就把整句机械改成过去式。
- 正文叙述句不得用冒号、分号或破折号引出解释、串联分句或插入补充。根据实际逻辑关系使用连词、从句或拆成完整句，不得仅删除标点而造成句子粘连，也不堆叠连词形成冗长句。公式、比值、固定术语中的符号、逐字引文和投稿格式明确要求的标点保留，不把连字符或数值范围连接号当作叙述性破折号删除。
- 仅在需要明确作者贡献、研究选择或责任归属时使用 `we`，不得连续多句以 `We` 开头，也不得逐段用 `We` 串联全文。其余叙述优先以具体方法、系统、实验或结果作主语，不为回避 `we` 而滥用被动语态或模糊成果归属。

## 组合边界

与 software 组合时区分代码正确性和实验有效性；与 proposal 组合时区分已经获得的结果与拟开展的工作。论文叙事与表达条款用于中英文论文的起草、翻译、润色与写作审查，不套用到要求如实回顾过程的工作汇报、实验记录或审稿回复。英文论文写作条款仅用于英文论文文本，不扩展到代码、普通技术文档或中文申报正文。不要因存在 `.bib` 文件就声称参考文献已核验。
